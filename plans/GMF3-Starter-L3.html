Aims & objectives
  • Main aim. By the end, learners will be better able to follow & act out the story «The secret message», break the alphabet code (A = 4, B = 8 … × 4) and ask how to spell: “How do you spell (message)? — M-E-S-S-A-G-E.”
  • Subsidiary. Say the alphabet a–z and the secret code rap (CD1 08); numbers 1–100 in a real task (the code wheel); double letters (mm = double m); story skills — predict → listen → sequence → act out; meet the story engine (Luke's travel blog).
  • Personal. Keep spelling snappy — letter NAMES only; spell in chunks of 2–3 letters with the class echoing; give every child a story role. Let the code-breaking be a team puzzle, not a race.
By the end, pupils can…
  • say/sing the alphabet a–z and spell familiar words aloud;
  • break the number-code to read a hidden word;
  • act out a story scene in a group.

Form
Letter NAMES for spelling (a /eɪ/, e /iː/, i /aɪ/…). The code: letter position × 4 → 4=A, 8=B, 48=L, 84=U. Double letters: ss = double s, mm = double m.
Pron. watch
letter names g /dʒiː/ vs j /dʒeɪ/; e /iː/ vs i /aɪ/ (classic traps); numbers 40–100 in the code (forty, sixty, eighty).
Concept checks (CCQs) · Assumptions
“Spell — do I say the WORD or the LETTERS?” → the letters.
“In the code, letter A = number 4. So B = …? Count in fours!” → 8.

Assumptions: Alphabet letter-names known patchily from GMF2; numbers 1–100 revised in L1. First story of the year — the act-out routine needs a full model. Readers follow the story text in the book while listening.

21–31′
Break the code
desks, groups of 3

Crack it together (act. 4 of the story). Show the code key: Number four is the letter A. Count in fours — eight is B, twelve is C! Decode the story password as a class: 4-16-88-20-56-80-84-72-20 → A-D-V-E-N-T-U-R-E!

▶ Code-breaker teams (RallyCoach). Each group gets a short coded word (their group name) + the key card. Partner A reads a number, partner B finds the letter, then swap. First to decode shouts it — but everyone in the group must read it aloud.

🎮 Projector option: show the code wheel from PB p.7 on screen; a rotating child spins to a number, the WHOLE class calls the letter.

💪 Support: printed A=4 key card in view. ⭐ Extension: encode your OWN name into numbers for a partner.

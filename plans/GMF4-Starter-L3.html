Week 07.09–13.09 · Lesson 3✨ NEW · numbers 100–1000 + must / going to~10 pupils · groups of 3–4Pupil's Book pp.6–7 · AB pp.4–5
Aims & objectives
  • Main aim. By the end, learners will be better able to follow & act out the story «Welcome home, Luke!», say & use numbers 100–1000 (Luke's code machine) and make class rules: “We must (speak English in class). / We're going to (work together).”
  • Subsidiary. Say numbers 100–1000 and break the letter-code (A = 153 … Z = 999); recycle appearance language from L2 (Luke's beard/ponytail/freckles); Values — obligations & responsibilities in class; story skills — predict → listen → read along → act out; write our own class contract (AB).
  • Personal. Keep the code-breaking a team puzzle, not a race; give every child a story role. Model must (rule) vs going to (promise) with two clear gestures — don't over-explain, notice it.
By the end, pupils can…
  • say and read numbers 100–1000;
  • break the letter-code to read a hidden word;
  • make a class rule with must and a promise with going to.

Concept checks (CCQs) · Assumptions
“In the code, A = 153 and B = 177. Is each letter a NUMBER now?” → yes, a code number.
“We must speak English — is that something we HAVE to do or MIGHT do?” → have to — it's a rule.

Assumptions: Numbers to 100 revised in L1; the hundreds/thousands pattern is the new step. First story of the year — the act-out routine needs a full model. must & going to are met receptively; today they're noticed & used in a real task (the contract). Readers follow the story text while listening.

Story · Welcome home, Luke!
carpet

Predict. PB p.6, frame 1: Lily, Ravi and Josh are waiting for Luke. He looks different! What has he got now? 2–3 guesses (recast with He's got…).

Listen 1 — gist (CD1 06, books closed). Listen: what presents does Luke bring? → drums, a mask & snorkel, a code machine.

Listen 2 — read along (books open pp.6–7). Finger under the text; pause per frame: Luke! You look different. He's got a beard, a moustache, a ponytail and freckles! … I love playing the drums! … I love going snorkelling!

Comprehension. Thumbs up/down: Luke has got short hair now… thumbs! Ravi's present is a code machine… thumbs! — every child votes.

37–44′
Break the code
desks, groups of 3

▶ Code-breaker teams (RallyCoach). Each group gets a short coded word + the A=153 key card. Partner A reads a number, partner B finds the letter, then swap. First to decode reads it aloud — but everyone in the group must read it.

Whole-class solve (AB p.5 ex. 3). Decode Luke's message together on the board number by number; class calls each letter.

💪 Support: printed code key in view. ⭐ Extension: encode your OWN name into code numbers for a partner.

Our class contract
carpet → desks

Read & listen (PB p.7 act. 2, CD1 08). «Our class contract»: rules with must (We must speak English in class), promises with going to (We're going to work together). Two gestures: fist = rule, open hand = promise.

▶ RallyRobin rules. Pairs brainstorm one MORE class rule (must) + one promise (going to). Share 3–4 aloud; you write the best on our real class poster.

Write (AB p.5 ex. 2). Each child copies our agreed rules + promises into their contract.

✔ Assess: listen — do they use must for rules and going to for promises? Recast, note names.

ЧТО ДЕЛАЕМ: рисуем мечту: наше школьное кафе — что в нём БУДЕТ? собираю идеи, вбрасываю there's

👩‍🏫 Учитель — по шагам:
  1. Рисую на доске рамку-«помещение»: Imagine: OUR school café. What's inside? Shout ideas!
  2. Собираю 6–8 идей картинками/словами в «помещение» (pizza corner · juice bar · game zone…).

ЧТО ДЕЛАЕМ: таблицы ex.1 с жестами (is-палец/are-ладонь); ловушки TB как «мины»; блиц ex.2

👩‍🏫 Учитель — по шагам:
  1. Таблицы ex.1 заполняем ВМЕСТЕ с жестами: is — один палец (одна вещь), are — ладонь (много). Ключ: There's·There are·There aren't·Is there·there is·Are there.
  2. Три мины TB на плакат: ① There're ✗ (are не прячется!) ② Yes, there's ✗ (краткий ответ — полный!) ③ вопрос = переворот (Is there…?).
  3. Якорь-жест от have got: I'VE GOT a pen (рука на грудь). THERE'S a pen on the desk (рука на парту).
  4. Блиц ex.2 хором с жестами: 5 предложений is/are (ключ: are·is·is·are·are).
📺 Показываем: учебник p.42 · плакат «3 мины» (живёт до теста) · жесты
👦 Дети: заполняют таблицы с жестами, учат 3 мины, флипают блиц. Ожидаемо: жесты держат is/are. Типичная ошибка: мина ① — плакат уже висит, показываю молча.

ЧТО ДЕЛАЕМ: дрилл-игра: карточка «+/−/?» переворачивает предложение; мини-доски, 6 раундов

👩‍🏫 Учитель — по шагам:
  1. Правила: говорю предложение + показываю карточку: − = сделай отрицание, ? = вопрос, + = обратно.
  2. There's a cinema… (карточка −) … Boards up! (There isn't a cinema.) 8 сек.
  3. 6 раундов с ротацией (2 singular · 2 plural c any · 2 вопроса + краткий ответ хором: Yes, there is!).
  4. Команда с максимумом чистых досок +3.
📺 Показываем: карточки +/−/? · мини-доски · таймер
👦 Дети: флипают формы на досках одновременно — вовлечён каждый. Ожидаемо: к 4-му раунду скорость ×2. Типичная ошибка: aren't без any — эхо: «aren't ANY shops».

ЧТО ДЕЛАЕМ: 8 Key phrases: кто говорит (C или W?), дрилл с интонацией, скелет диалога на доску

👩‍🏫 Учитель — по шагам:
  1. Key phrases по одной: читаю — класс повторяет с интонацией; сортируем — customer или server? (TB Extra; ключ: C: Can I have · I'd like · That's all · How much; W: Would you like any/anything · Anything else? · That's…, please.)
  2. US↔UK из книги: fries (US) = chips (UK).
  3. Строю скелет диалога на доске (5 реплик со стрелками): Hi! Can I have ___, please? → Would you like any ___? → Yes, please / No, thanks. → Anything else? → That's all, thanks. How much is that? → That's $___.
  4. Прогон скелета хором ×2 с жестами (поднос, деньги).

ЧТО ДЕЛАЕМ: ролевая по шагам: THINK меню → PREPARE по скелету → PRACTISE шёпотом → PERFORM сценки; ротация ролей

👩‍🏫 Учитель — по шагам:
  1. THINK (2 мин): пары выбирают из меню p.43: main + drink (+ dessert по смелости). Бюджет: $10.
  2. PREPARE (4 мин): диалог по скелету доски, ключевые слова на карточку (не текст!). Reinforcement TB: проверяю a/an/some в заказах (a burger · some fries).
  3. PRACTISE (5 мин): шёпотом («radio whisper»), обмен ролями — каждый пробует официанта.
  4. PERFORM (7 мин): 3–4 пары у «стойки» (парта + меню); класс = peer review по 2 вопросам книги: ① What's the order? ② Are the Key phrases there? +2 за сцену, +1 слушателям за верный ответ ex.6.

  • Main aim. By the end, learners can describe places with there is/there are (aff/neg/questions) and order food politely with 4+ Key phrases in a scaffolded café role-play.
  • Subsidiary. Полный ввод there is/are (таблицы + жесты + Common errors TB как «ловушки»); практика на Lee Centre и нашем классе; round-up о кафе Гонконга с опорой; видео-модель (Коннор, $9.25); Key phrases по шагам; ролевая «кафе» по опоре в парах.

  • say/write there is/are in +, −, ?
  • ask Is there…? / Are there any…? with inversion

Structure
There's a cinema. · There are some cafés. · There isn't a bookshop. · Is there a baker's? — Yes, there is. · Can I have a burger, please? · How much is that?
Form
singular → there is/isn't · plural → there are/aren't (+ any); вопрос = переворот Is/Are there; краткий + БЕЗ сокращения: Yes, there is (не Yes, there's!).
Pron. watch
интонация вопроса вверх: Is there…?↗ (TB) · Can I have…?↗ вежливо · цены: two seventy.
Concept checks (CCQs) · Assumptions
“There is two cafés?” → plural → There ARE two cafés.
“Yes, there's — можно?” → No: полная форма в кратком ответе — Yes, there is.
“Заказ без please?” → Официант «не слышит»: politeness first.

Assumptions: have got (U2) и some/any (P3) — опоры сегодняшнего дня; there is/are — полностью новое как система. Key phrases заказа новые; цены = числа Starter. Ролевые по опоре уже были (U1 meeting people) — формат знаком.

Classroom management — signals
«Eyes up in 3-2-1» — count down calmly → all eyes on you at «1». No shouting over noise, ever.
Visible timer — timer on screen = we work; timer stops = pens/hands down. The timer is the boss, not you.
Volume dial — arm up/down = louder/quieter; «radio whisper» for rehearsals.
«Boards up!» — mini-whiteboard rounds: everyone commits, all boards up together — nobody hides, nobody shouts first.
One clap — two claps — you clap once, class answers with two and freezes — instant reset mid-game.
English-first — ideas in Russian are welcome, POINTS only for the English version — recast and repeat.

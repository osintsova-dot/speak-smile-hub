Aims & objectives
  • Main aim. By the end, learners will be better able to make polite requests with would like + quantifiers: “I'd like some / a lot of / lots of (cheese), please.” and ask: “Would you like (some olives)? / What would you like on your pizza?”
  • Subsidiary. Understand Josh & Grandma's café dialogue (CD2 21); discover the rule — I would = I'd, and questions change the word order (Grammar clue); recycle the 12 toppings from L1; write requests and a mini-dialogue (AB follow-up).
  • Personal. Drill I'd like as one polite chunk; make some vs a lot of / lots of visible with hands (small pinch vs big armful); keep the ordering game strictly timed; model the full request, accept short and recast.
By the end, pupils can…
  • ask & answer “Would you like…? — Yes, please. / No, thank you.”;
  • request with quantifiers: “I'd like a lot of cheese, please.”;
  • make a polite pizza-order dialogue with a partner.

Structure
What would you like on your pizza? — I'd like some (tuna), please.  ·  Would you like (a lot of onions)? — Yes, please. / No, thank you.
Form
I would like = I'd like + (quantifier) + food. Quantifiers: some (a little) · a lot of / lots of (a big amount). Question: Would you like…? / What would you like…?
Pron. watch
weak would you /wʊdjə/; I'd like /aɪd laɪk/ (one smooth chunk); rising Wh-intonation on the offer.
Concept checks (CCQs) · Assumptions
“I'd like — what two words is I'd?” → I would.
“some or a lot of — which is MORE cheese?” → a lot of / lots of!

Assumptions: 12 toppings are fresh from L1 (checked in warm-up). would like met before as a set phrase; the quantifier choice (some / a lot of / lots of) and the question word order are today's new focus. Pupils can read the dialogue speech bubbles & the grammar table.

19–27′
Noughts & Crosses · requests
desks, 2 teams

▶ Noughts & Crosses — pizza. 3×3 grid of topping pictures. To claim a cell, the team makes a full request — I'd like a lot of cheese, please! — then the other team OFFERS it back in chorus: Would you like some olives? Both sides speak every turn. Rotate the speaker.

🎮 Projector/board option: draw the 3×3 grid on the whiteboard; a rotating child taps the winning cell as the WHOLE team says the request aloud.

ICQ: Do you say “I'd like” or “I would like”? (→ I'd like!)

27–37′
Pizza-order info-gap
desks, pairs

Model first. You = waiter, a pupil = customer: Good evening! What would you like on your pizza? — I'd like some tuna and a lot of cheese, please. — Anything else? — Yes, please. Lots of olives!

▶ Talk Partners info-gap (act. 4-style). Pairs take waiter/customer roles + an order slip. Customer requests 3 toppings with quantifiers; waiter writes them, reads the order back. Swap roles. 4–5 exchanges.

✔ Assess: circulate with the class list — who uses some / a lot of / lots of correctly? Recast, note names.

💪 Support: request stems printed on the slip. ⭐ Extension: add: No, thank you. I don't like mushrooms.

37–46′
Order chain · Numbered Heads
carpet, circle

▶ Numbered Heads Q&A. Teams numbered 1–4. You (then a pupil) draw a topping + quantifier card: Would you like a lot of prawns? Teams huddle 10 sec; you call a number — that child answers politely (Yes, please! / No, thank you.). Point per correct polite answer. The number is random — everyone must be ready.

ICQ: Do you shout the answer or wait for your number? (→ wait!)

Aims & objectives
  • Main aim. By the end, learners will be better able to describe sea animals with 6 adjectives and make longer comparatives: “A (shark) is (more dangerous) than a (seahorse). An (octopus) is (prettier) than a (whale).”
  • Subsidiary. Sing «The sea animal rap» (CD2 44); discover TWO new rules — adjectives in -y take -ier (pretty → prettier), and LONG adjectives take more (dangerous → more dangerous); recycle the -er comparatives from L2; a real opinion game (AB follow-up).
  • Personal. Two rules today — keep them on two coloured boards side by side (-ier · more). Model with height/face gestures; insist on than; keep the game moving — max 30 sec per partner.
By the end, pupils can…
  • name 6 adjectives (heavy · ugly · pretty · colourful · intelligent · dangerous);
  • make -ier comparatives (pretty → prettier, heavy → heavier);
  • use more with long words: “more dangerous / more colourful / more intelligent”.

Structure
A (shark) is (more dangerous) than a (seahorse).  ·  An (octopus) is (prettier) than a (whale).  ·  A (dolphin) is (heavier) than a (seahorse).
Form
-y → -ier: pretty → prettier, heavy → heavier, ugly → uglier. Long word → more: dangerous → more dangerous, colourful → more colourful, intelligent → more intelligent. + than.
Pron. watch
prettier /ˈprɪtiə/; heavier /ˈheviə/; intelligent /ɪnˈtelɪdʒənt/ (soft g); dangerous /ˈdeɪndʒərəs/; colourful /ˈkʌləfʊl/.
Concept checks (CCQs) · Assumptions
“pretty → ? (it ends in -y!)” → prettier (y → ier).
“dangerous is a LONG word — do I add -er or use more?” → more dangerous!
“more prettier — right or wrong?” → wrong! Just prettier.

Assumptions: 12 sea animals + the -er comparative are active from L1–L3. big/small/fast/slow/long carry over. The 6 adjectives are new; the split rule (-ier vs more) is the key challenge. Readers can read short adjective words. (NB: КТП listed 10 adjectives — book's new set is these 6; the rest were the -er words from L2.)

Anticipated problems & solutions
Likely problemWhat you do
more + short/-y word (“more pretty / more big”)Two-board contrast: -y words → -ier · long words → more; sort each adjective onto the right board first.
Doubling forgotten in -ier (“heavyer”)Show the swap: heavy + ier; colour the change.
than dropped againKeep the [than] strip from L2 on the board; beat-echo the whole chunk.
Adjectives mispronounced (intelligent)Clap the syllables; one action per adjective (dangerous = shark teeth, pretty = sparkle hands).
Opinion game = argumentIt's opinion — both answers OK: “That's true / I think so too / I don't agree!”; keep it light.

10–19′
Presentation · adjectives + 2 rules
carpet → board

Present (act. 1, CD2 43). Icon cards: It's heavy! It's ugly! It's pretty! It's colourful! It's intelligent! It's dangerous! Choral ×3 + one action each.

Two rule-boards. Board A -y → -ier (pretty→prettier, heavy→heavier, ugly→uglier). Board B more (dangerous→more dangerous, colourful→more colourful, intelligent→more intelligent). Sort each adjective card onto the right board WITH the class.

▶ Take Off–Touch Down: Stand up if a shark is DANGEROUS!… if a seahorse is PRETTY! — everyone reacts every time.

💪 Support: icon carries the meaning. ⭐ Extension: read the adjective word without the icon.

Rap + grammar box
carpet → board

Say the rap (act. 2, CD2 44). PB p.54. First run listen & point; second join in with the gestures.

Grammar box (act. 3, CD2 45). Board: An octopus is prettier than a whale. A jellyfish is more dangerous than a squid. Grammar clue: -y becomes -ier. Long words take “more”. Never say “more prettier”! Circle -ier and more.

ICQ: “colourful” — colourfuler or more colourful? (→ more colourful!)

Opinion game · true or false
mingle → desks

Model first. Say a comparison, class judges: A jellyfish is more dangerous than a crab. — True or false?

▶ Quiz-Quiz-Trade (act. 4-style). Each child holds an animal-pair card + adjective. Music → mingle; off → pair: A A dolphin is more intelligent than a fish — true? B answers That's true! / I don't think so. TRADE cards, new partner. 5–6 exchanges.

✔ Assess: circulate — is it -ier for -y words and more for long words? Recast, note names.

💪 Support: card shows the full sentence. ⭐ Extension: add another comparison for the same pair.

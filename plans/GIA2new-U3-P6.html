🎯 Миссия пары — зачем она и как её подать
Зачем (для учителя): Две реальные вещи в одной паре: фразы, которые работают в настоящем магазине (их можно унести в поездку и в жизнь), и первый большой письменный продукт юнита. Для новичков диалог собирается по лестнице: видео → shadowing хором → готовый диалог с пропусками → свой по образцу. Описание фото — по такой же лестнице: вопросы → заметки → текст по скелету → чек-лист. because и so получают телесный якорь ещё на разминке.
Как представить детям (дословно, 30–40 сек):
“Today you learn the sentences that work in a real shop, in any country: How much is it? Can I try it on? Have you got this in a medium? First we watch Archie buy a sweater, then we say the phrases together, then you play the scene yourselves — with a script if you need one. And after that: your first photo description, step by step. Two words will hold it together: because and so.”
Суть по-русски, если нужно поддержать: учим фразы, которые работают в настоящем магазине; смотрим, как покупает Арчи, повторяем хором, играем сцену (можно по сценарию). Во второй половине — описание своего фото по шагам, со связками because и so.

ЧТО ДЕЛАЕМ: диалог по готовому тексту → замена вещи и цены на свои → два прогона со сменой ролей

👩‍🏫 Учитель — по шагам:
  1. Прогон 1: читаем диалог ex.5 по ролям, с карточками на партах. Read it twice — then swap roles.
  2. Kagan Inside-Outside Circle: внутренний круг — продавцы, внешний — покупатели; после раунда внешний сдвигается на одного. Текст диалога можно держать в руках.
  3. Прогон 2: меняем только ТРИ вещи — товар, цену и размер. Всё остальное берём из текста. Small changes — big confidence.
  4. Хожу и подсказываю жестами (показал рукой «over there», посмотрел на бирку «hold on», подал вещь «here you go»).

ЧТО ДЕЛАЕМ: два описания A и B: почему автору нравятся (ex.2), таблица где/что (ex.3), because и so (ex.4–5)

👩‍🏫 Учитель — по шагам:
  1. Читаем описание A вслух вместе, потом B. ex.2: Why does the writer like each photo? Ключ: A — интересное и смешное · B — им весело вместе.
  2. ex.3 таблица с опорой, заполняем вместе на доске. Ключ: A — 1 in front of a blue door · 2 a blue shirt, a hat. B — 3 in front of my house · 4 Jack: jeans, red trainers · 5 Ali: a yellow sweater · 6 Laura: a jacket, green glasses · 7 Me: a T-shirt, trousers, a blue hat.
  3. ex.4: находим в текстах по два because и два so, подчёркиваем цветом. Правило: 1 because — причина · 2 so — результат.
  4. ex.5 письменно с самопроверкой. Ключ: 1 so · 2 because · 3 because · 4 so · 5 because.
  5. Обращаю внимание: the photo — present continuous; 'I always wear hats' — present simple. Both, in one text.
📺 Показываем: SB pp.44–45 · цветные карандаши · ключ на слайде

ЧТО ДЕЛАЕМ: 6 вопросов → заметки → 4–6 предложений по скелету → чек-лист → обмен с партнёром

👩‍🏫 Учитель — по шагам:
  1. Шаг 1: Choose ONE photo (or draw one). Answer the six questions — NOTES only: where · why there · what you're wearing · who with · what they're doing · why you like it.
  2. Шаг 2: начала предложений на экране — In this photo, I'm … · I'm wearing … · … is wearing … · I like this photo because … Пишем 4–6 предложений. Word bank открыт.
  3. Шаг 3: чек-лист CHECK p.45 сам себе — present continuous для фото? present simple для привычки? because и so на месте?
  4. Шаг 4: обмен с партнёром по ex.8 (три вопроса) — партнёр подчёркивает, но НЕ переписывает.
  5. Описания на стену класса рядом с фото.

WB Unit 3 · чистовик описания — на стену класса
📋 Справка для подготовки (читать ДО урока, не в классе)
  • Main aim. By the end, learners can play a clothes-shopping dialogue using 8+ Key phrases and write a photo description following the model, with because and so.
  • Subsidiary. Видео с Арчи (ex.2–5); распределение фраз assistant/customer; модельные описания A и B; таблица ex.3; правило because/so (ex.4–5); чек-лист CHECK p.45.
  • Personal. Письмо в классе с моей поддержкой; никакого «допиши дома» — дома только переписать начисто. Диалог сначала хором за видео, потом за партой, к доске — добровольцы.
By the end, students can…
  • ask for an item, a price and a size in a shop
  • play a shopping dialogue with a partner
  • write 4–6 sentences describing a photo
  • use because for a reason and so for a result

Concept checks (CCQs) · Assumptions
«I'm just looking» и «I'm looking for» — одно и то же? → нет: первое «я просто смотрю», второе «я ищу».
«It's a bit small» — это грубо? → нет, обычная вежливая фраза в магазине.
«I like this photo so it's funny» — что не так? → нужна причина: because.
Фото описываем каким временем? → present continuous: I'm standing, I'm wearing.

Assumptions: SB pp.43–45, КТП пара 26. Скелет THINK→PERFORM из учебника; диалог у новичков идёт от готового текста к своему, не наоборот.

Classroom management — signals
«Eyes up in 3-2-1» — count down calmly → all eyes on you at «1». No shouting over noise, ever.
Visible timer — timer on screen = we work; timer stops = pens/hands down. The timer is the boss, not you.
Volume dial — arm up/down = louder/quieter; «radio whisper» for rehearsals.
«Boards up!» — mini-whiteboard rounds: everyone commits, all boards up together — nobody hides, nobody shouts first.
One clap — two claps — you clap once, class answers with two and freezes — instant reset mid-game.

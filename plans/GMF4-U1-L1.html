Aims & objectives
  • Main aim. By the end, learners will be better able to name 12 ingredients and ask if we have them: “Is there any (flour) in the cupboard? / Are there any (nuts) in the fridge? — Yes, there is. / No, there aren't.”
  • Subsidiary. Sing «Let's go shopping!» (CD1 11) & the vocabulary chant (CD1 10); brainstorm cake ingredients (Learning to learn); notice countable (are there any + plural) vs uncountable (is there any); early literacy — read ingredient words and sort them fridge/cupboard (AB).
  • Personal. Keep teacher-talk low; ICQ before every task; stirrer→settler rhythm — the memory game is high-energy, plan the freezes. Insist on any in the question and the right verb (is/are, there is/there aren't).
By the end, pupils can…
  • name the 12 ingredients;
  • ask “Is/Are there any…?” and answer “Yes, there is / No, there aren't”;
  • read ingredient words and sort them countable/uncountable.

Structure
Is there any (sugar) in the cupboard? — Yes, there is.  ·  Are there any (nuts) in the fridge? — No, there aren't.  ·  preview: How much / How many … do we need?
Form
Is there any + uncountable (flour, sugar, oil) · Are there any + plural countable (nuts, biscuits, raisins). Short answers: Yes, there is / are · No, there isn't / aren't.
Pron. watch
biscuits /ˈbɪskɪts/ (silent u); coconut /ˈkəʊkənʌt/ (3 syll.); raisins /ˈreɪzənz/; chocolate /ˈtʃɒklət/ (2 syll., not 3).
Concept checks (CCQs) · Assumptions
“flour — one flour, two flours? Is/Are there any?” → can't count it → IS there any.
“nuts — one nut, two nuts? Is/Are there any?” → count them → ARE there any.

Assumptions: Starter routines are back; pupils know some food from GMF3 (food category revised in the Starter). The 12 ingredients are largely NEW; Is/Are there any is known receptively — production is today's stretch. Readers — word cards work alongside pictures.

10–20′
Presentation · 12 ingredients
carpet → board

Present with flashcards + chant (act. 2, CD1 10). Each card: What's this? It's… flour! Oil! Nuts! Choral ×3 + one gesture (flour = sprinkle, nuts = crack, cream = swirl).

Is/Are there any? (act. 4 language). Board: two columns — uncountable (flour, oil, sugar, salt, jam, butter, coconut, cream) · countable (nuts, biscuits, chocolate chips, raisins). Hold each card — class chooses the column, then says: Is there any flour? / Are there any nuts?

▶ Take Off–Touch Down: Stand up if this is COUNTABLE… biscuits! — flash cards fast, everyone reacts every time.

💪 Support: answer with the gesture + word. ⭐ Extension: full sentence — Yes, there's some butter in the fridge.

28–36′
Kitchen memory game
carpet → desks, pairs

▶ Memory game (act. 4, Talk Partners). Pairs study the PB p.8 kitchen picture for 30 sec, then close books. A asks: Is there any sugar in the cupboard? Are there any nuts in the fridge? B answers from memory Yes, there is / No, there aren't. Open to check. Swap. Point per correct memory.

ICQ: Do you look at the picture while you ask? (→ no — from memory!)

✔ Assess: stand behind one pair — is it any + the right is/are?

Ingredient trade
mingle

▶ Quiz-Quiz-Trade. Each child holds an ingredient card. Music → mingle; off → pair: A shows the card, Is there any…? / Are there any…? B answers with the right verb, then swap, TRADE cards, new partner. 5–6 exchanges — everyone speaks many times.

Whole-class check: Hands up if you had a COUNTABLE ingredient!

ЧТО ДЕЛАЕМ: Kagan · Inside-Outside Circle: карусель знакомых вопросов с подсказками; я снимаю speaking-чек по одному в уголке

👩‍🏫 Учитель — по шагам:
  1. ▶ Kagan · Inside-Outside Circle: Two circles! Inside — question card (знакомая, с подсказкой). Ask! Answer! Swap roles. Outside — rotate two!
  2. Карточки — ярмарочная колода: сюрпризов нет, успех запрограммирован.
  3. Мой чек в уголке: по одному, 1–2 мин — 3 знакомых вопроса + 1 свободный; галочки в лист; хвалю конкретно.
  4. Карусель не останавливается: the circle never stops!
📺 Показываем: колода знакомых вопросов · мой чек-лист · уголок
👦 Дети: говорят все 18 минут по знакомым карточкам, пока я слушаю каждого лично — чек без очереди и страха. Ожидаемо: успеваю 8–10; остальных — на I-can блоке. Типичная ошибка: yes/no без деталей — подсказка карточки тянет полный ответ.

👩‍🏫 Учитель — по шагам:
  1. Протокол: дробь по коленям → имя → номинация → выход → сертификат + рукопожатие → фото → аплодисменты.

летний чек-лист (ассет)
📋 Справка для подготовки (читать ДО урока, не в классе)
  • Main aim. By the end, every learner has passed a friendly speaking check on familiar questions (с поддержкой) and received a certificate with a personal nomination.
  • Subsidiary. Разбор теста приватно и бережно (балл + 2 плюса); «I can»-мини-выступления по опоре; письмо себе в сентябрь по рамке; праздник и летний чек-лист.
  • Personal. Финал года нулевой группы: год назад эти дети не говорили по-английски ВООБЩЕ. Сегодня каждый ведёт диалог и получает сертификат. Проговорить этот путь каждому лично — в номинации.
By the end, students can…
  • hold a short interview on familiar questions
  • say 2–3 «I can» lines with examples
  • write 3 lines to September-self with the frame
  • leave proud with a certificate and summer kit

Structure
Интервью: знакомый вопрос с карточки → полный ответ (подсказка на карточке есть). I can: I can count — one, two, three… Письмо: Dear September-me, · This year I… · Don't worry — English is fun!
Form
интервью = карточки ТОЛЬКО знакомые (колода ярмарки); «I can» = строка + мини-пример; письмо = 3 строки по рамке.
Pron. watch
финал без дриллов — голос уверенный, улыбка, темп свой.
Concept checks (CCQs) · Assumptions
“Speaking — это экзамен?” → Это разговор со мной по вопросам, которые ты знаешь с ярмарки. С подсказками. Проверено: справишься.
“Сертификат дают за балл?” → За ГОД. Каждому. С личной номинацией — за твоё сильное.
“Летом всё забуду?” → Летний набор поможет не забыть — и мы напишем себе письмо-напоминание.

Assumptions: Тест проверен, листки (балл + 2 плюса + летний фокус) готовы; сертификаты подписаны, номинация КАЖДОМУ; колода интервью = знакомые вопросы ярмарки/QQT с подсказками.

Anticipated problems & solutions
Likely problemWhat you do
Расстройство из-за баллаБалл приватно, рядом ВСЕГДА 2 плюса; публично — только номинации; к расстроенным подхожу в карусели с личным «смотри, что выросло».
Ступор на speaking-чекеКарточки знакомые + подсказки; ступор → выбираю его самый уверенный вопрос (помню по ярмарке); диалог состоится.
Праздник в хаос2 игры из моего списка по голосованию, тайминг по 8 мин, сигнал one clap живёт и в праздник.
Слёзы прощанияЗаготовка: «сентябрь близко, группа продолжается» + летний чек-лист как ниточка; финал — общее фото, не прощание навсегда.
Родители ждут итоговМини-итоги родителям (балл + рост + план лета) — листком/сообщением после урока.
Classroom management — signals
«Eyes up in 3-2-1» — count down calmly → all eyes on you at «1». No shouting over noise, ever.
Visible timer — timer on screen = we work; timer stops = pens/hands down. The timer is the boss, not you.
Volume dial — arm up/down = louder/quieter; «radio whisper» for rehearsals.
«Boards up!» — mini-whiteboard rounds: everyone commits, all boards up together — nobody hides, nobody shouts first.
One clap — two claps — you clap once, class answers with two and freezes — instant reset mid-game.
English-first — ideas in Russian are welcome, POINTS only for the English version — recast and repeat.

WHAT WE DO: ex.9–10: delivering the messages to their addressees → everyone writes a REPLY to what they got → return → peer review

👩‍🏫 Teacher does — step by step:
  1. Delivery: the messages go out to real addressees (the draw guaranteed everyone a letter).

WB Unit 4 (pp.28–35) · notebook · points to the leaderboard next pair
📋 Preparation reference — read BEFORE the lesson, not in class
  • Main aim. By the end, learners can write two clear notes/messages with because in the right position (THINK→PREPARE→WRITE→CHECK) and reply to a classmate's real message — plus the unit's Quick review is done, with a cumulative Starter–U4 strip.
  • Subsidiary. Subskill because (the reason after, subject+verb); the message format Hi…/See you!; peer review with 3 ticks; Quick review p.57 as a team quiz + the ARCHIVE strip (be·have got·some/any·there is/are) — a direct Mid-year warm-up.
  • Personal. Lesson A = THINK→PREPARE (models+because+plan), lesson B = WRITE→CHECK + review — by the KTP. Writing in portions, the class works like a live messenger: the text has a real addressee.
By the end, students can…
  • match messages to replies and name format tools
  • place because correctly (+ subject + verb)
  • write 2 messages 25+ words with a reason each
  • survive a cumulative Starter–U4 quiz strip

Target language
Lexis
Hi / Hello / Dear / Hey …See you later! / Thanks, / Love,because + subject + verbRemember to… / Please don't… / Do you want to…?
Structure
Remember to come home early because you've got a maths exam. · Do you want to…? · Please don't… because… · That's fine. / Great idea!
Form
because sits in the MIDDLE of the two parts; the reason comes AFTER because; after because — subject + verb; the start Hi/Hello/Dear/Hey, the finish See you later!/Thanks/Love.
Pron. watch
because /bɪˈkɒz/ (not “bekos”) · the intonation of a request: Please don't… ↓ softly.
Concept checks (CCQs) · Assumptions
“Because my book is green this isn't my English book — OK?” → No: the main clause first, then because + the reason.
“After because — just a noun?” → No: subject + verb.
“A message with no addressee and no signature — is that a message?” → That's a note into the void: Hi + a name, a finish + a signature.

Assumptions: PS and questions work well after P3–P4; because is known orally, the written position + message format are new. Quick review is doubled with a cumulative strip: the unit closes right before Mid-year. Gate is diagnosis, not humiliation: the ceiling must be REAL (time-in-words / -s spelling / question word order), results are private tallies, the reveal is “so THIS is our growth zone”.

Classroom management — signals
«Eyes up in 3-2-1» — count down calmly → all eyes on you at «1». No shouting over noise, ever.
Visible timer — timer on screen = we work; timer stops = pens/hands down. The timer is the boss, not you.
Volume dial — arm up/down = louder/quieter; «radio whisper» for rehearsals.
«Boards up!» — mini-whiteboard rounds: everyone commits, all boards up together — nobody hides, nobody shouts first.
One clap — two claps — you clap once, class answers with two and freezes — instant reset mid-game.
English-first — ideas in Russian are welcome, POINTS only for the English version — recast and repeat.

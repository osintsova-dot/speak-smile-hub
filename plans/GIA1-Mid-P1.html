👩‍🏫 Учитель — по шагам:

(никто не раскладывает за всех). 4 мин; проверка хором с якорем: got-question → no do! · routine/like → do/does · describing → is/are · food on the table → there is/any.
  3. Якорь-таблица остаётся на доске ВЕСЬ урок — это спасательный круг марафона.
📺 Показываем: слайд 10 вопросов · якорь-таблица 4 колонок

👩‍🏫 Учитель — по шагам:
  1. S-Starter: спеллинг-код (раскодируй 3 слова + закодируй 1) + числа на слух от судьи. S-U1: карта: страна→nationality + 2 предложения о месте (It's amazing/busy…). S-U2: «монстр»: карточка существа → описать have got + body/hair (It's got three green eyes…). S-U3: меню кафе: сортировка C/UC + заказ с some/any. S-U4: расписание: время словами + 3 routine-предложения с чистым -s о «человеке дня».
  2. Ротация по свистку каждые 6 мин; на станции — карточка-задание + перевёрнутая опора (взял = −1).
  3. Судьи станций — ротация из экипажей (Timer-роль); я хожу и собираю в блокнот ТИПИЧНЫЕ ошибки для разбора.
  4. Очки: чистота выполнения × без опоры.
📺 Показываем: 5 станционных карточек · опоры перевёрнутые · таймер/свисток
👦 Дети: проходят все 5 блоков полугодия ногами — движение + ретривал. Ожидаемо: U1–U2 подзабыты сильнее — так и задумано вскрыть. Типичная ошибка: смешивание has got/has — блокнот, разберём в марафоне.

ЧТО ДЕЛАЕМ: грамм-марафон по Kagan Showdown: 5 ворот подряд (be → have got → some/any/there → present simple → mix); каждый пишет каждый раунд, доски вверх по команде

👩‍🏫 Учитель — по шагам:
  1. Ворота = 3 задания на мини-досках, ВСЕ пишут одновременно, по команде SHOWDOWN! доски вверх разом: Gate be: She ___ from Italy · they ___n't happy · ___ you OK? Gate have got: вопрос+краткий ответ+possessive 's. Gate food: some/any/there is-are в 3 пропусках. Gate PS: aff+neg+вопрос c 3-м лицом (watch/study ловушки). Gate MIX: 3 предложения, где надо ВЫБРАТЬ структуру.
  2. Чистый залп экипажа (все доски верны) = +2; топ-ошибки — сразу микро-дрилл 20 сек хором.
  3. Стратегии теста вешаю по ходу: Strategy 1: read the task TWICE. Strategy 2: easy first. Strategy 3: final check = hunt the -s.
📺 Показываем: мини-доски · слайды ворот · плакат 3 стратегий
👦 Дети: пишут каждый раунд каждый — никто не отсиживается; ворота MIX вскрывают кашу. Ожидаемо: be/have got чисто, MIX — 60–70%. Типичная ошибка: Does she has — хоровой фикс: does + ГОЛЫЙ глагол.

ЧТО ДЕЛАЕМ: финал: эстафета «исправь чужой пробник» — экипажи получают листы с типовыми ошибками (мой блокнот дня!) и чинят на скорость

👩‍🏫 Учитель — по шагам:
  1. Раздаю каждому экипажу лист «неизвестного ученика» с 8 ошибками — это ТИПИЧНЫЕ ошибки сегодняшних станций/марафона (из моего блокнота, обезличено).

  4. Финал: If you can CATCH the mistake, you won't WRITE it on Tuesday.

  • Main aim. By the end, learners have recycled ALL Starter–U4 language through team stations and a grammar marathon, located their personal gaps and set test-taking strategies for the Mid-year test.
  • Subsidiary. 5 лексических станций (Starter/U1/U2/U3/U4) пройдены каждым экипажем; грамматический марафон be→have got→C/UC→there is/are→present simple; стратегии теста (read the task twice · easy first · check -s) отработаны на мини-пробнике.

Structure
полугодие одним списком: I'm from… / She's got… / There is some… / Is there any…? / He gets up at… / Do you like…? — переключение структур без смешивания.
Form
be (all forms); have got (all forms); possessive 's; countable/uncountable + some/any/a lot of; there is/there are; Present simple (aff/neg/questions + 3rd person -s) — фокус на «переключатель»: КАКОЙ глагол-помощник в этом вопросе?
Pron. watch
аккумулятор полугодия: nationalities ударение · /h/ в have · some /sʌm/ · -es /ɪz/ (watches) · time-слова (half /hɑːf/).
Concept checks (CCQs) · Assumptions
“Have you got…? и Do you have lessons…? — где какой помощник?” → have got = got-вопрос без do; present simple = do/does.
“Is there any milk — почему any?” → вопрос → any (some в утверждении).
“В тесте застрял на №3 — что делаешь?” → easy first: пропусти, вернись в конце.

Assumptions: Весь язык Starter–U4 пройден и тестирован поюнитно; смешивание структур (has got vs does) — главный риск полугодового теста. Формат станций знаком по юнитам. Gate is diagnosis, not humiliation: the ceiling must be REAL (spelling! numbers by ear! alphabet at speed!), results are private tallies, the reveal is “so THIS is our growth zone”.

Classroom management — signals
«Eyes up in 3-2-1» — count down calmly → all eyes on you at «1». No shouting over noise, ever.
Visible timer — timer on screen = we work; timer stops = pens/hands down. The timer is the boss, not you.
Volume dial — arm up/down = louder/quieter; «radio whisper» for rehearsals.
«Boards up!» / «Showdown!» — mini-whiteboard rounds: everyone commits, all boards up together — nobody hides, nobody shouts first.
One clap — two claps — you clap once, class answers with two and freezes — instant reset mid-game.
English-first — ideas in Russian are welcome, POINTS only for the English version — recast and repeat.

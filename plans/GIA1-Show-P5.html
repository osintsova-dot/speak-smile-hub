ЧТО ДЕЛАЕМ: демо монтажа за 4 минуты на моём телефоне: порядок → обрезка → титры; тайм-боксы дня

👩‍🏫 Учитель — по шагам:
  1. Живое демо на проекторе: беру 2 своих дубля из P4-демо — Order… cut the start… cut the end… title: ‘Our English Room’. Done. FOUR minutes.
  2. Тайм-боксы на слайд: ORDER 8′ → CUT 8′ → TITLES 6′ → export. Таймер правит.
  3. Параллельные задания ролей: speaker+writer — language check + 15-сек анонс; director — intro-речь премьеры.
  4. ICQ: Effects and music? — Only AFTER titles, if time. Minimum first!
📺 Показываем: мой телефон + проектор · слайд тайм-боксов
👦 Дети: смотрят демо-монтаж и разбирают параллельные роли. Ожидаемо: «это всё?» — да, минимум смотрится профессионально.

ЧТО ДЕЛАЕМ: монтажный спринт: editor режет по тайм-боксам, команда параллельно — language check, анонс, intro-речь

👩‍🏫 Учитель — по шагам:
  1. Запуск таймера: ORDER — eight minutes, go! Далее CUT, TITLES по свистку.
  2. Обхожу editor'ов: чиню только «застрял в меню»; творческие решения — команде.
  3. Language check параллельно: speaker+writer слушают каждый дубль в наушник/тихо — галочка по чек-листу: фразы чистые? титры-спеллинг проверен соседями?
  4. Director пишет intro-речь премьеры (2 предложения: Our guide is about… Enjoy!).
📺 Показываем: телефоны · чек-лист языка · черновики титров (обмен на спеллинг-чек)
👦 Дети: монтируют и проверяют язык параллельно — заняты все роли. Ожидаемо: к 33-й минуте у большинства собрано. Типичная ошибка: editor полез в эффекты — тайм-бокс возвращает.

ЧТО ДЕЛАЕМ: Kagan · Showdown (мини-доски): языковой rewind года — каждый пишет ответ сам, капитан командует «Showdown!», вскрываемся одновременно

👩‍🏫 Учитель — по шагам:
  1. ▶ Kagan · Showdown: у каждого мини-доска, в команде — капитан раунда (ротация). Question up → EVERYBODY writes, no talking! Captain: ‘SHOWDOWN!’ — boards up together, compare, agree on the best answer.
  2. Вопросы мешаю по языку сезона и года: Say a guide phrase for a tour! · A connector for facts! · How do you order food? (U3) · Ask about last weekend! (U7)
  3. Чистый залп команды (все доски верны) = +2; капитан меняется каждый раунд.
  4. 6–8 раундов, темп высокий — двигаются руки, работает каждый.
📺 Показываем: мини-доски у каждого · список вопросов (по банкам P1)
👦 Дети: пишут ВСЕ одновременно и вскрываются по команде капитана — никто не отсиживается за спиной сильного. Ожидаемо: азарт под конец пары. Типичная ошибка: списывают до showdown — «no talking till the call!»

Concept checks (CCQs) · Assumptions
“Монтаж — это спецэффекты?” → No: порядок + обрезка + титры. Минимум, который смотрится.
“Титры по-русски можно?” → Титры — на английском: это часть Language-оси.
“Голосовать за свою команду?” → No — жетон только чужому видео.

Assumptions: Материал снят на P4 (+ДЗ-докадры); у editor'ов любой стандартный телефонный редактор (iMovie/CapCut/встроенный — без разницы, операции те же). Wi-Fi не нужен: всё локально, показ с телефона через кабель/AirPlay или просто с телефона по рядам, если проектор недоступен.

Classroom management — signals
«Eyes up in 3-2-1» — count down calmly → all eyes on you at «1». No shouting over noise, ever.
Visible timer — timer on screen = we work; timer stops = pens/hands down. The timer is the boss, not you.
Volume dial — arm up/down = louder/quieter; «radio whisper» for rehearsals.
«Boards up!» — mini-whiteboard rounds: everyone commits, all boards up together — nobody hides, nobody shouts first.
One clap — two claps — you clap once, class answers with two and freezes — instant reset mid-game.
English-first — ideas in Russian are welcome, POINTS only for the English version — recast and repeat.

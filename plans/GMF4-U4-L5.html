Aims & objectives
  • Main aim. By the end, learners will be better able to read & say the /eɪ/ sound spelt a_e and eigh (a snake had a race in space · came eighth · neigh · sleigh), talk about an observatory in Australia, and read & plan a fact file — three mini-blocks, one “space” thread.
  • Subsidiary. Phonics: notice that a_e and eigh both spell /eɪ/ (recognise → say → sort, next to ai · ay); culture — the Siding Spring Observatory in Australia (dark clean skies · 12 telescopes · nebulas) + video, 21C: grading things on a cline (hot↔cold · big↔small); literacy — text type a fact file (gas giants · Mars), subheadings, plan & write a fact file about Earth.
  • Personal. Three blocks — keep transitions crisp (chant/action bridges); the snake-in-space tongue-twister is play; cap each block hard so the fact file actually gets planned.
By the end, pupils can…
  • say the /eɪ/ twister and sort a_e / eigh words;
  • name 2–3 facts about the Australian observatory + order things on a cline;
  • find the parts of a fact file and plan one with a partner.

Structure
A horse and a snake had a race in space. The snake came eighth.  ·  There are 12 telescopes at the observatory.  ·  fact file: Size — it's the biggest planet. Moons — it's got at least 16 moons.
Form
/eɪ/ = a_e (snake, race, space, came — split digraph) AND eigh (eighth, neigh, sleigh) — (also ai: rain · ay: day). Fact-file layout: subheadings (Distance · Size · Rings · Moons · Interesting information).
Pron. watch
/eɪ/ clean in snake/race/space/came; eighth /eɪtθ/; sleigh /sleɪ/; nebula /ˈnebjələ/; observatory /əbˈzɜːvətri/.
Concept checks (CCQs) · Assumptions
“race and eighth — same /eɪ/ sound? Same letters?” → same sound, different spelling (a_e vs eigh)!
“A fact file — facts or opinions? Has it got subheadings?” → facts, in sections with subheadings.

Assumptions: Space words, superlatives (short & long) are active (L1–L4). Sound–letter awareness from GMF3 phonics is enough to enjoy the a_e / eigh noticing (по учебнику). Pupils can read the short fact-file texts with support.

Block 1 · Phonics /eɪ/ (a_e · eigh)
carpet → desks

Speak and spell (act. 1, CD2 25). PB p.45: A horse and a snake had a race in space. The snake came eighth and the horse said ‘neigh’ and went away on a sleigh. Remember! rain · day. Listen, then the speed ladder: slow → fast → whisper. Pairs test each other ×3.

Sort the /eɪ/ spellings. Hoops/columns: a_e (snake, race, space, came) · eigh (eighth, neigh, sleigh) · (spares: ai — rain · ay — day). Hold up word cards — every child points/steps to the right hoop BEFORE you place each card.

Notice the rule. Snake and sleigh — same sound /eɪ/, different letters! a_e has a magic e; eigh is four letters together. (notice, don't lecture).

💪 Support: say the word, teacher shows the hoop. ⭐ Extension: add one more /eɪ/ word to a hoop (cake, eight, play).

✔ Assess: who still reads a_e as short /æ/? Note them — extra RallyRead next unit.

Block 3 · Literacy · a fact file
carpet → desks, pairs

Read a fact file (PB pp.46–47, act. 1–2, CD2 27–28). «The gas giants» (Jupiter · Saturn · Uranus · Neptune) & «Mars»: Which planet has got the biggest moon? Which is the windiest? Which is the coldest? Read/listen; find the subheadings (Distance · Size · Rings · Moons · Interesting information).

▶ Fact-file scavenger hunt. Race in pairs to find on PB pp.46–47: Which is the second biggest planet? How many moons has Saturn got? What are Saturn's rings made of? First hands up read the answer aloud — everyone scans.

Writing tip (PB p.47). A fact file has facts, not opinions. We divide it into sections. Each section has a subheading! Chorus the subheadings.

▶ Plan a fact file (Cooperative learning, AB p.44 format). Pairs plan a fact file about Earth: What's it made of? · What does it look like? · What has it got (mountains · oceans · ice caps)? · Weather · Position in the solar system. 2 pairs share one section aloud.

💪 Support: fill the plan template with word support. ⭐ Extension: write full sentences under each subheading.

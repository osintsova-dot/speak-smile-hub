👩‍🏫 Учитель — по шагам:
  1. Квадрат 7 хором: Was he famous? · regular = +ed · went, did, saw, took.
  2. Ex.7 братья Райт — ВМЕСТЕ, по предложению: читаю → класс предлагает форму → пишем (invented · were · wanted · studied · wasn't · lasted · travelled · continued). Интересный факт TB: первый полёт — 12 секунд!

  4. Ex.8 два образца вместе (№2–3): I didn't see the match. Did you see the match? — хором; остальные пары делают сами по образцу №1 в книге (он напечатан!).

ЧТО ДЕЛАЕМ: закрепление игрой: бинго по стене через Kagan Numbered Heads + мягкий fix-it через Kagan Showdown

👩‍🏫 Учитель — по шагам:
  1. ▶ Wall bingo + Numbered Heads Together: у команд сетка 3×3 с номерами квадратов. Number off one-two-three! I read a task — heads together, find the square, agree the answer. Then I call a number — that person answers for the team.
  2. Задание-образец: «скажи негатив: She likes football» → квадрат 4 → doesn't like → клетка закрыта. Три в ряд = BINGO (+3).
  3. 8–10 заданий по всем квадратам, с опорами на доске.
  4. ▶ Мягкий fix-it = Showdown: предложения из рамки «Мы это разобрали» (наши сегодняшние находки!) — Fix it in secret on your board… Showdown — boards UP!
  5. See? The mistakes we CAUGHT today — you fix them in seconds now.
📺 Показываем: сетки бинго 3×3 · список заданий · мини-доски

📋 Справка для подготовки (читать ДО урока, не в классе)
  • Main aim. By the end, learners can work through the 9-square grammar wall with colour-coded support (green squares = «умею сам», yellow = «с таблицей», red = «разберём вместе») and solve the colour exercises in pairs using Quick review columns.
  • Subsidiary. Механика стены освоена спокойно (квадрат-правило → упражнение); опорные таблицы юнитов легальны всю пару; трудные места (past simple, superlatives) разобраны ВМЕСТЕ без гонки; «поймай ошибку» в мягкой версии.
  • Personal. По КТП: «квест в парах с опорными таблицами… разбор трудных мест без стресса». Никаких таймеров-удавок на красных квадратах. Ошибка = находка для разбора, не минус.
By the end, students can…

Concept checks (CCQs) · Assumptions
“Можно смотреть в таблицу юнита?” → Yes! Жёлтый квадрат = «с таблицей» — это стратегия.
“There are some water?” → No: water uncountable → There IS some water.
“Did you went?” → No: после did — глагол-словарь: Did you GO?

Assumptions: Все 9 точек года введены по линии с нуля; свежие (past simple U7–8, superlatives) ещё сырые — на них закладываем совместный разбор, не самостоятельную гонку. Цветовая разметка стены снимает страх: видно, где сам, где с опорой, где вместе.

Classroom management — signals
«Eyes up in 3-2-1» — count down calmly → all eyes on you at «1». No shouting over noise, ever.
Visible timer — timer on screen = we work; timer stops = pens/hands down. The timer is the boss, not you.
Volume dial — arm up/down = louder/quieter; «radio whisper» for rehearsals.
«Boards up!» — mini-whiteboard rounds: everyone commits, all boards up together — nobody hides, nobody shouts first.
One clap — two claps — you clap once, class answers with two and freezes — instant reset mid-game.
English-first — ideas in Russian are welcome, POINTS only for the English version — recast and repeat.

🎯 Why this lesson looks like this — the design in one card
Why (for the teacher): The animal-description lexis is not introduced as a list but as a zoologist's working tool: the crew builds a file on a species (class · habitat · body parts · adjectives) and reads it out WITHOUT the name — the class has to identify it. Precision becomes the condition for winning, not a demand from the teacher: one wrong detail and the class names a different animal. The 'Top five animal videos' clip is watched as material for a top five of their own, not as 'just a video'.
How to announce it (say this, 30–40 seconds):
“Zoologists, open your files. Every animal on this planet has a file: class, habitat, body parts, three adjectives. Today each crew builds one — and then reads it out WITHOUT the name. If the class can't identify your animal, your file is useless. One wrong detail and they name the wrong species. Sixty seconds, judges watching. Files open!”
The gist, if you need to restate it: each crew builds a file on an animal — class, habitat, body parts, three adjectives — and reads it out without the name. If the class cannot identify the species, the file counts as useless.

crews

WHAT WE DO: the level for our students: the language of species that are gone (the first use of was/were — with no grammar announced) + a negative detail in the description

👩‍🏫 Teacher does — step by step:
  1. Weak file: 'It's big.' Useless — a zoologist gives a contrast.
  2. Upgrade frames: It's got a fin, but it isn't a fish. · It hasn't got feathers or fur. · There WAS a bird like this — the dodo. Now there isn't.
  3. Put the three lines on the board and ask them to build their own: One line with BUT, one line with a negative, one line about an animal that is already gone.
  4. Two upgrade lines in your file = richness points.

👦 Students do: rewrite 2 lines of the file more precisely. Expect: they pick up 'there was' intuitively — exactly what is needed in P2–P3. Error: 'there were a bird' — don't correct out loud, tick it for the clinic

Product: the blind file
PRODUCT · the blind file
crews → stage

WHAT WE DO: the blind file: 60 sec of description with no name; the class identifies the species in 20 seconds

👩‍🏫 Teacher does — step by step:
  1. Preparation 7 min: Four lines: class, habitat, two body parts, two adjectives. Everyone owns one line. No scripts — keywords only.
  2. Rehearsal on ex.7 p.73: Student A thinks of an animal, Student B asks Yes/No questions: Is it a mammal? Is it colourful? — this is how they test whether the file works.
  3. Sixty seconds per crew. The class has twenty seconds to name the animal. Judges: fluency, accuracy, richness — cards up!
  4. A challenge from the class after each one: You said 'marine'. Then why has it got fur?
📺 On screen: 60-second timer · judges' cards · rubric
👦 Students do: perform in their roles, the class identifies. Expect: a file nobody identifies = a live analysis of what was missing. Error: reading off the paper — the judges cut fluency

📋 Preparation reference — read BEFORE the lesson, not in class
  • Main aim. By the end, crews can describe an animal with class, habitat, body parts and adjectives (12 animals · 9 body parts · 6 adjectives) so precisely that the class identifies it from the description alone.
  • Subsidiary. The gate exposes the real vocabulary ceiling; the class table p.72 ex.1–2 and the body parts ex.3 are closed as a race; ex.5 (track 36) and ex.6 against the clock; the Yes/No guessing game ex.7 becomes the rehearsal for the product; Video skills is watched with an analyst's task.
  • Personal. The past tense is NOT announced as the topic: was/were only appear in the bonus level, in the talk about extinct animals. Form errors (has got / have got, 'It's got striped') go into the log silently — they are the material for the clinic in P3.
By the end, students can…
  • name 12 animals and put them in the right class
  • label 9 body parts on a photo
  • use 6 adjectives (colourful, dangerous, marine, poisonous, spotted, striped)
  • describe an animal so the class can identify it

Form
the frame on SB p.73: 'The tiger IS a striped animal', but 'It's GOT striped fur' — an adjective goes with be, a body part with have got.

Concept checks (CCQs) · Assumptions
'A shark is a mammal' — can we say that? → no: a shark is a fish, it does not fit the table in ex.2 (TB key).
'It's got striped' — correct it. → It's got striped FUR / It IS striped.
'You have been describing animals for four years. But 15 words in 90 seconds, spelled correctly?' → the gate.

Classroom management — signals
«Eyes up in 3-2-1» — count down calmly → all eyes on you at «1». No shouting over noise, ever.
Visible timer — timer on screen = we work; timer stops = pens/hands down. The timer is the boss, not you.
Volume dial — arm up/down = louder/quieter; «radio whisper» for rehearsals.
«Boards up!» — mini-whiteboard rounds: everyone commits, all boards up together — nobody hides, nobody shouts first.
One clap — two claps — you clap once, class answers with two and freezes — instant reset mid-game.
English-first — ideas in Russian are welcome, POINTS only for the English version — recast and repeat.

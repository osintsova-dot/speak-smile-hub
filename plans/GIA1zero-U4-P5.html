  • Main aim. By the end, learners can write two short notes/messages with because (по шагам THINK→PREPARE→WRITE→CHECK, порциями, с банком фраз) and reply to a classmate's message from response frames.
  • Subsidiary. Subskill because (позиция + subject+verb) с опорой-схемой; формат Hi…/See you!; peer review по галочкам; Quick review со взаимопомощью + мягкая архив-полоса (be·have got·some/any) с опорными таблицами — подготовка к Mid-year без страха.
  • Personal. Урок А = THINK→PREPARE (модели, because, план, черновик), урок Б = WRITE→CHECK + Quick review — по КТП. Письмо порциями по 3–4 предложения; у каждого сообщения настоящий адресат — мотивация встроена.
By the end, students can…

  • place because correctly with the scheme
  • write 2 messages (3–4 sentences each) from a scaffold
  • do the unit Quick review with team support

Concept checks (CCQs) · Assumptions
“Because he's ill Rory isn't in school — OK?” → Нет: главное сначала, because с причиной после.
“After because: ‘because homework’?” → Нет — because I'VE GOT homework (subject + verb).
“Сообщение без имени сверху — кому оно?” → Никому: Hi + имя обязательно.

Assumptions: PS + вопросы рабочие после P3–P4; because слышали в речи, письменная позиция и формат сообщений — новое. Первое «жанровое» письмо юнита — порции и банки фраз обязательны.

Classroom management — signals
«Eyes up in 3-2-1» — count down calmly → all eyes on you at «1». No shouting over noise, ever.
Visible timer — timer on screen = we work; timer stops = pens/hands down. The timer is the boss, not you.
Volume dial — arm up/down = louder/quieter; «radio whisper» for rehearsals.
«Boards up!» — mini-whiteboard rounds: everyone commits, all boards up together — nobody hides, nobody shouts first.
One clap — two claps — you clap once, class answers with two and freezes — instant reset mid-game.

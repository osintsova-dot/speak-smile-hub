📋 Preparation reference — read BEFORE the lesson, not in class
  • Main aim. By the end, learners can write two short notes/messages with because (step by step THINK→PREPARE→WRITE→CHECK, in portions, with a phrase bank) and reply to a classmate's message from response frames.
  • Subsidiary. Subskill because (position + subject+verb) with a diagram support; the Hi…/See you! format; peer review with ticks; Quick review with mutual help + a gentle archive strip (be·have got·some/any) with support tables — Mid-year prep without fear.
  • Personal. Lesson A = THINK→PREPARE (models, because, plan, draft), lesson B = WRITE→CHECK + Quick review — per the KTP. Writing in portions of 3–4 sentences; every message has a real addressee — the motivation is built in.
By the end, students can…
  • match messages to replies
  • place because correctly with the scheme
  • write 2 messages (3–4 sentences each) from a scaffold
  • do the unit Quick review with team support

Form

Pron. watch

Concept checks (CCQs) · Assumptions
“Because he's ill Rory isn't in school — OK?” → No: the main clause first, because with the reason after.
“After because: ‘because homework’?” → No — because I'VE GOT homework (subject + verb).
“A message with no name at the top — who's it for?” → Nobody: Hi + a name is compulsory.

Assumptions: PS + questions are working after P3–P4; because has been heard in speech, the written position and the message format are new. The unit's first “genre” piece of writing — portions and phrase banks are compulsory.

Anticipated problems & solutions
Likely problemWhat you do
Fear of the blank pageNever “write a message” with no support: skeleton + phrase bank + model in front of them; the first line is written together.
because at the startThe scheme [main clause] + because + [subject+verb] on the board; a finger check against the scheme before handing in.
They write slowly, don't finish in timePortions against the timer: one message = 6 minutes, 3–4 sentences. Less is fine: quality > length.
Peer review makes them shy2 ticks maximum + the rule “positive + 1 tip”; the reviewer signs it — this is help, not a verdict.
Review before Mid-year is scaryAn archive strip WITH open support tables: success is guaranteed; “revise = remember, not learn again from scratch”.
Classroom management — signals
«Eyes up in 3-2-1» — count down calmly → all eyes on you at «1». No shouting over noise, ever.
Visible timer — timer on screen = we work; timer stops = pens/hands down. The timer is the boss, not you.
Volume dial — arm up/down = louder/quieter; «radio whisper» for rehearsals.
«Boards up!» — mini-whiteboard rounds: everyone commits, all boards up together — nobody hides, nobody shouts first.
One clap — two claps — you clap once, class answers with two and freezes — instant reset mid-game.
English-first — ideas in Russian are welcome, POINTS only for the English version — recast and repeat.
